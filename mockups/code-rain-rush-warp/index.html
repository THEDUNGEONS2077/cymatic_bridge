CODE RAIN EQ · RUSH × WARP · THREE BLENDS

C1's streams of code round the core, with C5's speed, mixed three ways: by time (the warp comes on the beat), in layers (the warp sits behind the code) and by distance (the warp is what's close to you). All three keep the rules: each stream listens to one band and its colour shows which; louder means faster and longer; heads flare on the beat; the core at the centre is the one focus. Pick one, or say what to move between them.

C1's code, with C5's warp arriving on the beat: the streams lunge forward on every kick.

  • Without a beat it's C1: calm streams of code round the core (watch the breakdown).
  • Each beat surges the flight: trails stretch and streaks of light grow behind the code, then ease away.
  • Surges overlap a little, so a busy track keeps faint streaks between beats.

C8 · LAYERS

C1's code in front, C5's warp behind it.

  • The streams of code stay as calm and readable as C1.
  • Behind them, thin lines of light fill the whole view and carry the speed: drifting specks when it's calm, long streaks when the beat surges.
  • Two depths of motion, one focus.
C9 · STRETCH

C9 · STRETCH

Code near the core, streaks near you: glyphs melt into light as they rush past.

  • Far off, the streams are crisp code closing in on the core.
  • As a stream nears you, its trail turns into a streak; the head stays a glyph.
  • Each beat surges: the streaks reach further in, then ease back.
  • The code spreads wider than C1's (C5's "everywhere"), with space kept round the core.
